# Aram Duel Moba

Мобилен уеб прототип за дуели, вдъхновен от еднолинейния формат ARAM и touch
управлението на Wild Rift. Използваме собствени правила и временни геометрични
обекти. Проектът не е свързан с Riot Games.

## Текуща цел

Да проверим дали движението, прицелването и бойната механика са удобни и забавни
на телефон. Един автоматично зареден герой, локална симулация и тренировъчна
цел; без избор на герой, акаунти, онлайн противник или игрови backend.
Vite обслужва файловете при разработка и не е мултиплейър сървър.

Текущата имплементация е **начална визуална сцена**, а не играем дуел: арена,
фиксирана камера, заместител на героя и заместител на тренировъчната цел.
Движение, контроли, щети и ARAM системите все още не са реализирани.

## Стартиране

Изисквания: Node.js 22.12+ и npm. Препоръчително Node.js 24 LTS.

```bash
npm ci
npm run dev
```

Отвори показания от Vite локален адрес. За телефон стартирай `npm run dev:lan`, свържи го към същата мрежа
като компютъра и отвори `http://<LAN-IP-на-компютъра>:5173`. Позволи достъп до
порта през локалната защитна стена при нужда. Използвай хоризонтална ориентация.
При хоствана тестова версия използваме HTTPS.

```bash
npm run typecheck
npm run build
npm run preview
```

Продукционният build се записва в `dist/`. `preview` е за проверка на build-а.
Няма нужда от променливи на средата, база или външни ресурси за началната сцена.

## Технологии и структура

TypeScript + Babylon.js (WebGL) + Vite. npm lockfile фиксира инсталацията.

| Път | Отговорност |
| --- | --- |
| `src/main.ts` | Стартиране, render loop, resize и освобождаване на ресурси |
| `src/game/` | Babylon сцена, камера и визуални обекти |
| `src/simulation/` | Бъдещи правила без зависимост от рендериране |
| `src/style.css` | Размер на canvas, safe area и начален интерфейс |
| `docs/RULES.md` | Предложени правила и граници на прототипа |
| `docs/TASKS.md` | Номерирани задачи и критерии за приемане |
| `docs/VALIDATION.md` | Реално извършени проверки и оставащи проверки |

Контроли, HUD и дефиниции на умения ще получат отделни модули, когато започнем
съответните задачи. Засега няма празни сървърни пакети или сложен monorepo setup.

## План

1. Правила и обхват — настоящата спецификация е работен draft.
2. Техническа основа — настоящият scaffold.
3. Арена, движение и сблъсъци.
4. Мобилно управление и насочване.
5. Локален бой срещу тренировъчна цел.
6. Полигон за бързо тестване и настройване.
7. Допълнителни ARAM механики след проверка на основния бой.
8. Мобилни тестове и споделима локална демо версия.

Подробностите и отметките са в [задачите](docs/TASKS.md). Онлайн 1v1 е отделен
бъдещ етап, извън този план. Първо изпълняваме 3–6 и проверяваме механиката.

## Работен процес

Една малка задача на branch/PR. В PR описваме резултата, направените проверки и
оставащите ограничения. Преди сливане изпълняваме `npm run build` и проверяваме
засегнатото поведение. За симулацията добавяме смислени тестове при реализацията
на движение и бой; за touch управлението правим проверки на реални устройства.
