За локална работа `npm run dev` използва 127.0.0.1. `npm run dev:lan` е за
обикновена разработваща машина и телефон в същата мрежа; тук LAN достъпът не е

мина при стартиране и заявка в един процес.

283 kB gzip). Това е базов engine scaffold; оптимизацията на imports и реалният
мобилен FPS остават за измерване. NullEngine не доказва визуална коректност,
touch поведение или GPU производителност.

## GitHub публикуване

Потребителят създаде начален README в main (commit acb573d). Интеграцията
съобщи успех за създаване на branch, но git fetch и повторното изброяване
показват само main. Създаване на tree/blob връща `KeyError: sha`, а създаване
на файл — `KeyError: commit`. Няма потвърдено качване на проектните файлове
или PR. Директният git push също няма HTTPS автентикация.

## Ръчни проверки при следващо стартиране

1. `npm ci`, след което `npm run dev`.
2. Видими са арена, син герой и оранжева цел; няма грешки в конзолата.
3. Resize и завъртане не разтягат canvas; portrait показва подсказка.
4. Следващите игрови контроли все още не са реализирани.
