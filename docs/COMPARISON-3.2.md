# Задача 3.2 — план и сравнение

Двата branch-а започват от картата `a886921`. `sol-6.1-medium` остава
непроменен; `astra-6-medium` реализира задачата от тази обща основа.
Имената обозначават сравнителните варианти, не удостоверяват модела
или reasoning настройката на изпълняващия чат.

## План за изпълнение

1. [x] Чист branch от общата карта и уточнен обхват само 3.2.
2. [x] Чиста симулация: 60 стъпки/секунда, 5 единици/секунда, диагонали.
3. [x] Desktop адаптер: WASD/стрелки, screen-space оси, прекъсвания.
4. [x] Отделен герой и интерполация между симулационните позиции.
5. [x] Автоматични проверки, build и desktop WebGL smoke.
6. [x] Документиране на резултатите и процедурата за сравнение.

## Конкретни разлики

| Област | sol-6.1-medium | astra-6-medium |
| --- | --- | --- |
| Времева стъпка | Самостоятелен fixedStep модул с callback | Акумулатор в createMovement |
| Състояние | Изменя position и пази facing | Чист step връща нова позиция; затворено състояние с копия при четене |
| Изобразяване | Последната симулационна позиция | Интерполация previous/current; 16.7 ms закъснение |
| Подготовка за умения | Пази последна посока | Последна посока предстои при добавяне на умения |
| Обхват | Движение без сблъсъци | Същият обхват и същата карта |

Интерполацията е архитектурна разлика, а не измерено доказателство,
че единият вариант е по-добър. На 60 Hz разликата може да е малка.

## Визуално сравнение

Стартираният вариант е на http://127.0.0.1:5174/. За последователно
сравнение спри dev сървъра, превключи branch и стартирай същата команда:

```powershell
git switch sol-6.1-medium
npm run dev -- --port 5174
# След сравнение и спиране на сървъра:
git switch astra-6-medium
npm run dev -- --port 5174
```

На всеки вариант: reload, „Близък изглед“, D и W, след това диагонал.
Провери W+S, W+↑, отпускане и връщане от друг tab/приложение.
Използвай един и същ viewport и zoom. Героят може да излезе от картата;
reload връща началната позиция. Бой и мобилно управление предстоят.

За директна проверка на кода след commit:

```powershell
git diff sol-6.1-medium..astra-6-medium -- src tests
```

Резултатите и ограниченията на проверките са в VALIDATION.md.
